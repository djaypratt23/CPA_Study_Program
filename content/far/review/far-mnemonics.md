| Hook | Stands for |
|---|---|
| **OWNES** | Finance lease criteria: **O**wnership transfers · **W**ritten purchase option reasonably certain · **N**et PV is substantially all of FV · **E**conomic life — term is a major part · **S**pecialized asset |
| **"CPTAR"** — the five revenue steps | **C**ontract · **P**erformance obligations · **T**ransaction price · **A**llocate · **R**ecognize |
| **PER** for accounting changes | **P**rinciple → retrospective · **E**stimate → prospective · **E**rror → **R**estate |
| **"Probable + estimable = book it"** | Loss contingencies: accrue only when both hold |
| **"Existed at year-end? Adjust. Arose after? Announce."** | Subsequent events: recognized vs. disclosed |
| **"Cash flows: pay the owners in financing"** | Dividends *paid* are financing; interest paid and dividends received are operating (U.S. GAAP) |
| **"Premium: expense < cash; discount: expense > cash"** | Bond amortization direction |
| **"Specialized or builds something"** | NFP contributed services recognition test |
| **"FIFO likes NRV; LIFO likes market"** | Inventory write-down tests |

## Two-minute self-test

1. A stock dividend in July — do you weight the new shares from July? *(No — retroactive to the start of the period.)*
2. Goodwill impairment step 2? *(Gone — one step, capped at goodwill.)*
3. Where do equity securities' fair value changes go? *(Net income.)*
4. Minimum or best estimate for a probable loss range? *(Best estimate; the minimum only when no amount is better.)*
