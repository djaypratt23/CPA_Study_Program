> Tax year 2025, reflecting the One Big Beautiful Bill Act (P.L. 119-21). Amounts marked † came from that law — confirm them against current exam materials (see REVIEW.md).

## Individuals

| Item | 2025 amount |
|---|---|
| Standard deduction † | $15,750 single/MFS; $31,500 MFJ/QSS; $23,625 HOH |
| Additional standard deduction (65+ or blind) | $2,000 unmarried; $1,600 married (each) |
| Senior deduction (2025–2028) † | $6,000 per person 65+; phase-out above $75,000 / $150,000 MAGI |
| Qualifying relative gross income limit | Less than $5,200 |
| Dependent's standard deduction | Greater of $1,350 or earned income + $450 |
| Child tax credit † | $2,200 per child under 17 (refundable up to $1,700); phase-out $200,000 / $400,000 |
| Credit for other dependents | $500 |
| Dependent care credit | 20%–35% of $3,000 / $6,000 |
| AOTC / LLC | $2,500 per student / $2,000 per return; phase-out $80,000–$90,000 ($160,000–$180,000 MFJ) |
| SALT cap † | $40,000 ($20,000 MFS); phased down above $500,000 MAGI, not below $10,000 |
| Mortgage acquisition debt limit | $750,000 |
| Medical floor / casualty floor | 7.5% of AGI / $100 + 10% of AGI |
| Charitable limits | Cash 60%; LTCG property 30% (public charities) |
| Tips / overtime deductions (2025–2028) † | Up to $25,000 / $12,500 ($25,000 MFJ); phase-out above $150,000 ($300,000 MFJ) |
| Car loan interest deduction (2025–2028) † | Up to $10,000; phase-out above $100,000 ($200,000 MFJ) |
| QBI deduction | 20%; threshold $197,300 single / $394,600 MFJ |
| Traditional IRA | $7,000 (+$1,000 at 50); active-participant phase-out $79,000–$89,000 single, $126,000–$146,000 MFJ |
| HSA | $4,300 self-only / $8,550 family (+$1,000 at 55) |
| Student loan interest | $2,500; phase-out $85,000–$100,000 single, $170,000–$200,000 MFJ |
| Capital loss deduction | $3,000 ($1,500 MFS) |
| §121 exclusion | $250,000 / $500,000 |
| Passive rental allowance | $25,000, phased out between $100,000 and $150,000 MAGI |
| Social Security wage base | $176,100 |
| SE tax | Net profit × 92.35% × 15.3%; deduct half |
| Additional Medicare / NIIT | 0.9% / 3.8% above $200,000 single, $250,000 MFJ |
| AMT exemption | $88,100 single / $137,000 MFJ; phase-out at $626,350 / $1,252,700 |
| Kiddie tax threshold | $2,700 of unearned income |
| Gift annual exclusion / lifetime exemption | $19,000 / $13,990,000 ($15,000,000 in 2026 †) |

|---|---|

| NOLs | Indefinite carryforward; 80% of TI; no carryback |
| Corporate capital losses | Back 3, forward 5 (short-term) |
| §179 † | $2,500,000; phase-out above $4,000,000 |
| Bonus depreciation † | 100% for property acquired after January 19, 2025 |
| Organization / start-up costs | $5,000 each (phase-out above $50,000); rest over 180 months |
