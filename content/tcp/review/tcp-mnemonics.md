| Hook | Stands for |
|---|---|
| **"BAPE"** | Loss limit order: Basis, At-risk, Passive, Excess business loss |
| **"90 / 100 / 110"** | Estimated tax: 90% of this year, 100% of last year, 110% if last year's AGI > $150,000 |
| **"2 from grant, 1 from exercise"** | ISO qualifying disposition |
| **"83(b) in 30"** | File the §83(b) election within 30 days of transfer |
| **"Tuition and treatment are free"** | Direct tuition and medical payments are excluded from gifts without limit |
| **"Gain uses donor, loss uses FMV"** | Dual-basis rule for gifted loss property |
| **"3-4-5 for returns"** | Due in the 3rd month (1065, 1120-S), 4th month (1040, 1120, 1041, 709), 5th month (990) |
| **"Cash, hot, then the rest"** | Order for allocating basis in partnership distributions |
| **"Only cash, receivables, inventory — then a loss"** | Loss on a liquidating partnership distribution |
| **"Hot assets are ordinary"** | §751 on the sale of a partnership interest |
| **"AAA before E&P"** | S corporation distribution ordering |
| **"Debt basis heals first"** | S corporation income restores debt basis before stock basis |
| **"600 / 300 / 100"** | Fiduciary exemptions: estate / simple trust / complex trust |
| **"Trade, regular, unrelated"** | The three UBTI tests |
| **"50 / 200 / 500"** | 990-N receipts / 990-EZ receipts / 990-EZ assets (thousands) |
| **"Solicit tangible, stay safe"** | P.L. 86-272 |
| **"Recapture now, gain later"** | Installment sales recognize depreciation recapture in the year of sale |
| **"45 to name it, 180 to close it"** | §1031 deadlines |
| **"179, bonus, MACRS"** | Cost recovery order |
| **"40% in Q4 flips to mid-quarter"** | MACRS convention test |
